Wordの中で、
論文を探す・ためる・引用する。

臨床工学の研究者・学生のための論文ライブラリです。PubMedで探した論文をZoteroにため、書いている原稿にそのまま引用できます。

FOR

こんなときのために作っています

Mendeleyから移りたい

ためてきた論文は、Zoteroの読み込み機能でフォルダやPDFごと移せます。その上で、このライブラリから使います。

英語の論文を原稿から離れずに引く

PubMedの論文を、Wordの窓から探して、そのまま原稿に引用できます。

引用の抜けや取り違えが心配

原稿に入っている引用を一覧にして、どの論文を引いているかを確かめられます。

FEATURES

できること

Wordの「ホーム」タブから窓を開くだけ。原稿から離れずに、文献の作業が進みます。

01 探す

PubMedを検索

英語の語句でPubMedを探します。題名・著者・雑誌・年・DOIが並びます。

02 ためる

ボタンひとつでZoteroへ

「保存」で自分のZoteroに入ります。同じ論文は二重に入りません。PDFもZoteroで一緒に管理できます。

03 引用する

原稿のカーソルの位置に差し込む

Zotero形式の引用として入るので、書式や文献リストはZoteroのWordボタンで整えられます。

HOW IT WORKS

論文も原稿も、あなたのPCに残ります

  • 論文とPDFは、あなたのZoteroの中。このライブラリが預かることはありません。
  • 原稿は、あなたのWordの中。外へ送りません。
  • 外へ出るのは検索の語句だけ。PubMedへ、探すために送ります。
  • 窓がつながるのは、そのPCのZoteroだけ。橋渡しのプラグインは、この窓からの要求にだけ答えます。

GETTING STARTED

はじめ方

準備は最初の1回だけです。お配りしているインストール一式（zip）を使います。

Claude Code か Codex がある方

フォルダを開いて「インストール」と言うだけ

  1. zipを展開し、そのフォルダを Claude Code か Codex で開きます
  2. 「インストール」と言います
  3. AIが、Zoteroを入れるところから順に案内します。Windowsの「許可しますか？」で「はい」を押すことと、Zoteroの画面で数回クリックすることだけお願いします

元に戻すときも、同じフォルダで「アンインストール」と言えば戻せます。

AIを使わない方は、次の3つを順に

Zoteroを入れる

無料の論文管理ソフトです。起動すると、WordにZoteroのボタンも入ります。Mendeleyの論文もここで読み込めます。

橋渡しを入れる

Zoteroの「ツール → プラグイン」から、Siromegane Bridge を入れます。

Wordに窓を入れる

一式の中のファイルをダブルクリックして登録すると、「ホーム」タブにボタンが出ます。手順は一式のマニュアルにあります。

使える環境（試作版）　Windows ／ Word は Microsoft 365 または Office 2024 以降 ／ Zotero 7 以降
Office 2021 以前のWordでは、引用の機能が動きません。試作版のため、いまは限られた範囲で試しながら改良しています。

SOURCES

PubMedのみ、つないでいます

論文を探す先として、このライブラリがつないでいるのはPubMedだけです。

  • ほかの論文データベースは、規約で申請が要ることがあります。例えばJ-STAGEは、WebAPI利用規約（第2条）で、営利目的で使うときは有償・無償に関わらずJSTへの利用申請が必要とされています。
  • このライブラリは、営利目的にあたると判断しました。無料でお配りしていますが、しろめがね先生の発信活動の一部として配っているためです。
  • ほかの雑誌やデータベースをつなぎたい方は、ご自身でどうぞ。例えばJ-STAGEなど、よく読む論文が載っている先があれば、Claude CodeやCodexなどのAIに「自分のPCで、○○のAPIで論文を探せるようにして」と頼むと、ご自身用の仕組みを作れます。
  • その場合は、つなぐ先の規約をご自身で読んで守ってください。例えばJ-STAGEは、非営利で使うなら申請は要りませんが、「Powered by J-STAGE」の表示などの条件があります。つないだものを人に配ったり、営利目的で使ったりするときは、JSTへの申請が必要です。J-STAGE WebAPI利用規約

ROADMAP

これから足していくこと

いちばん作りたいのは、AIと一緒に原稿と論文を突き合わせる機能です。

  • 引用の当てはめ：原稿のどの文に、どの論文が根拠として使えるかを示す
  • 食い違いの指摘：原稿の数値や結論と、引用した論文の中身が合わないところを示す
  • 日本語で探す：日本語で聞くと、AIがPubMed用の検索式を作る
  • 自分の論文とつなぐ：自分の論文と、そこで引用した文献をまとめる
  • 臨床工学の辞書：分野ごとの仕分けと、略語（ECMO、CHDFなど）での検索

AIの提案には、必ず論文の該当する一文を並べ、ご自身の目で確かめられる形にする予定です。
